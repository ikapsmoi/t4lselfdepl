# Tomorrowland Search Intent and URL Ownership

**Reviewed:** 24 October 2026

## Ownership principles

- Separate official ticket-information intent from Travel4life travel-package and planning intent.
- Keep one primary URL for each distinct query family; use edition guides for destination-specific status.
- Never imply that a Travel4life quote or travel package includes a ticket unless the named written offer confirms it.
- Do not create a standalone Tomorrowland France route: the current French Alps event is Tomorrowland Winter at Alpe d'Huez.
- Keep Brazil ticket status in the central ticket guide; no separate Brazil travel landing page is justified by the available evidence.
- Preserve existing URLs and the two permanent redirects already in place.
